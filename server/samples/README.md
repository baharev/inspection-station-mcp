# Sample photos

Photos from a real camera (1920x1080), of objects on a white surface, served by the fake
camera ("Sample photos" in the server's list of cameras, or `CAMERA=fake`) one per photo
taken, in name order. Brand names on the objects are erased. What Claude answered about
them is in the main README, [Inspecting the sample photos: verdicts and mistakes](../../README.md#inspecting-the-sample-photos-verdicts-and-mistakes).

| File | Scene |
|---|---|
| `01-tray-complete.jpg`, `02-tray-incomplete.jpg` | Tool tray, complete; hammer missing, a table knife in its place |
| `03-watches-behind.jpg` | Three wristwatches, the left one a few minutes behind |
| `04-packs.jpg` | Three foil packs: one torn, one folded at a corner, one crumpled |
| `05-scale-lit.jpg`, `06-scale-unlit.jpg` | Digital scale with a 50 cent coin, display lit and unlit |
| `07-gauge.jpg` | Analog thermometer and humidity gauge |

To try the server on other objects, put your own `.jpg` photos here (or point
`SAMPLES_DIR` to another folder).
